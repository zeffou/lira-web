Sources

External projects and services used by LIRA for Discovery and optional on-device transcription. Your imported personal library stays on device.

  • WhisperKit On-device speech-to-text for optional audiobook transcripts.
  • Hugging Face Model hosting used when transcription is first enabled.
  • LibriVox Public-domain audiobook catalog used in Discovery.
  • Project Gutenberg / Gutendex Public-domain ebook catalog used in Discovery.
  • Open Library Book metadata and public-domain ebook discovery.
  • Internet Archive Media resolution for selected public-domain titles.
  • Apple frameworks Playback, speech synthesis, lock-screen controls, and system pickers.
