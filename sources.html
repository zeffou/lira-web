Sources

External projects and services used by LIRA. Your imported personal library stays on device. Optional Sign in with Apple and Lira Pro use Apple and, for the profile only, Supabase.

  • Sign in with Apple Optional account authentication. Apple may provide a user identifier, name, and email or Hide My Email relay.
  • Supabase Optional profile storage: display name in the database and avatar images in Storage when you sign in and set a photo.
  • App Store / StoreKit Lira Pro monthly and yearly auto-renewable subscriptions, billing, and cancellation.
  • WhisperKit On-device speech-to-text for optional audiobook transcripts.
  • Hugging Face Model hosting used when transcription is first enabled.
  • LibriVox Public-domain audiobook catalog used in Discovery.
  • Project Gutenberg / Gutendex Public-domain ebook catalog used in Discovery.
  • Open Library Book metadata and public-domain ebook discovery.
  • Internet Archive Media resolution for selected public-domain titles.
  • Apple frameworks Playback, speech synthesis, lock-screen controls, system pickers, and Sign in with Apple.
